Dandy's Gym Log - installable app

Host this whole folder (index.html, manifest.webmanifest, sw.js, icons/) on any HTTPS host,
e.g. Netlify Drop: https://app.netlify.com/drop - drag the "dandys-gym-log" folder onto the page.
Then open the site URL in Chrome on Android and choose Install app.

Your data is stored on the phone. Use Plan > Export backup regularly.
